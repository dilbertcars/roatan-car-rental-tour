# roatan-car-rental-tour

A modern, responsive marketing website for a Roatan car rental and tour operator business.

## Included
- Hero section with reservation form
- Services overview for rentals and tours
- Fleet showcase
- Featured island tour packages
- Reviews and trust section
- Contact information and footer
- Mobile-responsive navigation

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
